# CLAUDE.md

以下の指示に従って。セッション内でユーザーから同じルールに関する指示がある場合はそちらを優先

## 会話のルール

- 常に日本語で会話
- 平易な文章になることを心がける
- 自然な日本語の文章にして。助詞は特に重要なので使い方に気をつける

## 実装のルール

- その方がより良い実装になるのであれば、既存実装やそこでの判断は無視する
- YAGNI原則を強く意識する

## 作業のルール

- GitHubのリポジトリが見たいときは、まず先に~/ghq以下を探す
- ghqになければghq getでcloneする

## コミットメッセージのルール

- 英語で書く
- 変更の目的が分かる簡単な1文にする
- コミットにはCo-Authorをつける

## Pull Requestのルール

- PRのタイトルは英語、説明文は日本語で書いて
- PRの説明文は変更の目的が分かる簡単なものにして

## ファイル変更後のルール

ファイルを変更した後、以下を実行して

1. プロジェクトの指定した検証手順があり、それが未実施であれば実施する
2. 現状の変更差分を全て確認する
3. 過去の経緯に関する実装・コメント・テストがあれば削除
4. このブランチに紐づくPRがある場合は、必要に応じてタイトルと説明文を更新
